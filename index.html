🎵 MusicWave

Этот проект создан как демонстрация навыков Frontend-разработки. Все данные и аудио берутся из официального iTunes Search API, что гарантирует легальность контента.

Стек: Чистый JavaScript (ES6+), HTML5, CSS3 (Grid/Flexbox), Web Audio API (визуализация), LocalStorage (сохранение истории и лайков).

Особенности: Адаптивный дизайн, кастомный плеер, алгоритм «Моя волна», скелетон-загрузка.
